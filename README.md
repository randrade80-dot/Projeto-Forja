# PROJETO FORJA

Não é sobre mudar o corpo. É sobre construir uma nova versão de si.

App pessoal de treino, alimentação, medidas e fotos. Funciona offline (PWA) e guarda tudo no próprio aparelho (IndexedDB), sem servidor nem conta.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub (ex.: `projeto-forja`).
2. Envie **todos** os arquivos desta pasta para a raiz do repositório (botão *Add file > Upload files*), incluindo `.nojekyll`.
3. Vá em *Settings > Pages*, em *Source* escolha *Deploy from a branch*, branch `main` e pasta `/ (root)`, e salve.
4. Em 1 a 2 minutos o app abre em `https://SEU-USUARIO.github.io/projeto-forja/`.

## Instalar no celular
Abra o link no Chrome (Android), menu ⋮ > *Instalar app* / *Adicionar à tela inicial*.

## Backup
Os dados ficam só neste navegador/aparelho. Use *Mais > Exportar backup JSON* com frequência. Para trocar de aparelho, exporte e importe o arquivo.
Atenção: o endereço do app define onde os dados ficam; mudar de usuário ou repositório começa um app vazio (importe o backup).
